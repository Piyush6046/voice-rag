Chunking Strategies
01

Semantic Chunking

Groups sentences by cosine similarity using the embedding model. A new chunk begins when similarity drops below the threshold. Captures coherent semantic units.

Primary strategy
02

Fixed-Size Overlap

Fixed word windows with overlap. Rich metadata: chunk_index, passage_id. Safety net ensuring no boundary information is lost.

Recall safety net
03

Sentence Window

Groups consecutive sentences together with overlap. Best for preserving sentence boundaries that fixed token windows would break.

Precision booster
Guardrail Layers
IN
Input Safety Filter
Regex-based detection of unsafe/harmful/jailbreak content patterns before any retrieval
OUT
Off-Topic Guard
Checks if the best retrieval score exceeds the similarity threshold — refuses if the corpus likely doesn't cover the query
OUT
Grounding Check (Token F1)
Answer must achieve minimum token overlap with retrieved context to be accepted
OUT
LLM Hallucination Self-Check
Second-line LLM-based check: asks "is this answer supported by the context?" before falling back to refusal
